# Semaforo-com-botao-com-debounce-e-fila-de-espera-LEGENDADO
Sistema de semáforo inteligente para pedestres utilizando ESP32, desenvolvido em C no ESP-IDF. O projeto conta com debounce de botão, controle de estados dos LEDs, gerenciamento de pedidos de travessia e lógica automatizada de sinalização.
